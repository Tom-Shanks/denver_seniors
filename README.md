# Denver Senior Residents and Library Access

**July 2020** · Denver and the surrounding metro area, Colorado

Where did concentrations of residents aged 65 and over fall relative to library and nursing-home locations? Tom Shanks assembled and published this map as an exploratory input for Denver Public Library mobile-library planning, as described in his [original portfolio](https://tom-shanks.github.io/).

[Open the interactive map](https://tom-shanks.github.io/denver_seniors/). Use the layer checkboxes and percent-age-65-plus legend to compare the population and facility layers. Select a feature to see the attributes bundled with the export.

## Sources and methods

- The [preserved export](data/) includes block-group identifiers and population and age fields, plus separate library and nursing-home point layers. Some population fields refer to 2010. The exact release and facility-data publishers are undocumented in this repository.
- [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) provide the reference basemap.
- The QGIS/qgis2web export shows a classified percentage choropleth and facility overlays. Leaflet provides the controls and popups.

The map documents historical distributions. It contains no verified travel-time, coverage, or service-outcome analysis. The transferable work is bringing demographic and facility data into one inspectable spatial view while preserving their provenance limits.
